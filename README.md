# Контрольная точка № 6 — MantisBT

Репозиторий содержит итоговые материалы КТ № 6 по настройке и проверке MantisBT.

## Состав

- `КТ6-MantisBT.docx` — итоговый отчёт в формате DOCX.
- `КТ6-MantisBT.pdf` — итоговый отчёт в формате PDF.
- `kt6-report-data.md` — структурированные данные, использованные в отчёте.
- `rest-api-evidence.md` — сведения о проверке REST API.
- `rest-api-response-sanitized.json` — обезличенная минимальная выборка ответа REST API.
- `evidence/` — скриншоты выполненной настройки MantisBT.

Секреты, API-токены, пароли, cookies и заголовки авторизации в репозиторий не включены.
